# Bounded Identity Confirmation for Vehicle MTMCT

Code accompanying **“Bounded Identity Confirmation for Online Vehicle Tracking across Nonoverlapping Cameras.”**

The system tracks vehicles within each camera, builds exit-to-entry handoff candidates, and buffers global predictions until an identity is committed or a fixed deadline expires. Committed identities are immutable. The experiments compare confirmation deadlines **0, 2, 4 and 8 frames** using identical local tracking streams.

This release supports desktop replay on **RoundaboutHD** and **CityFlowV2**. No model training is required. Supplied detector outputs and a pretrained vehicle ReID model are used.

## 1. Install

Use Python 3.12. Run these commands in this repository:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[test]"
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts/verify_release.py
```

On Linux/macOS, replace `.venv\Scripts\python.exe` with `.venv/bin/python`. Dataset-dependent checks skip when `CITYFLOW_DATASET_ROOT` is unset. The locked package versions come from the paper environment; see [reproducibility notes](docs/REPRODUCIBILITY.md).

## 2. Obtain the inputs

Download the datasets separately under their access terms:

- **RoundaboutHD:** extracted camera folders `imagesc001`–`imagesc004`, videos, raw `detection/labels_xy.zip`, SCT and multi-camera annotations.
- **CityFlowV2 / AICity22 Track 1:** the original dataset root containing `validation/S05`, `cam_timestamp`, `cam_framenum`, `cam_loc` and `eval`. Keep all S05 cameras: evaluation constructs transitions before selecting cameras 29, 33, 34 and 35.
- **Vehicle ReID:** download `osnet_ain_x1_0_vehicle_reid.onnx` using the URL in [model provenance](configs/vehicle_reid.json), or use your existing copy. The launcher checks its SHA256.

Videos, annotations, weights and generated caches are not included.

## 3. Run the paper experiments

First replace the example paths with your own. Preparation checks the input layout and creates portable configuration files without running tracking:

```powershell
.venv\Scripts\python.exe scripts/publication.py cityflow --dataset "D:\datasets\AICity22_Track1_MTMC_Tracking" --stage prepare
```

Build the observation cache, verify it, and run the CityFlow deadline comparison and published association baseline:

```powershell
.venv\Scripts\python.exe scripts/publication.py cityflow --dataset "D:\datasets\AICity22_Track1_MTMC_Tracking" --model "D:\models\osnet_ain_x1_0_vehicle_reid.onnx" --stage all
```

Run the RoundaboutHD validation interval:

```powershell
.venv\Scripts\python.exe scripts/publication.py roundabout --dataset "D:\datasets\RoundaboutHD" --model "D:\models\osnet_ain_x1_0_vehicle_reid.onnx" --cohort validation --stage all --baseline
```

Repeat with `--cohort test` and `--cohort all4` for the other reported intervals. Use `--stage cache` or `--stage run` to run stages separately. Cache extraction and completed studies resume after verifying their inputs. If inputs change, use a new `--work` folder.

## 4. Find the outputs

Outputs appear in `work/runs/`. They include predictions, local predictions, identity messages, publication timestamps, metrics, deadline diagnostics, comparison tables and signed run manifests. This reproduction launcher does not create annotated videos.

The manuscript's derived numerical summaries are in `results/reference/`. They are reference evidence, not outputs generated by a fresh installation.

## Scope, citation and license

These experiments evaluate bounded identity commitment and its output-availability tradeoff. The published baseline is an association adaptation on shared local tracks; its scores are not a reproduction of the authors' complete original pipeline. Detector inference time is unavailable for supplied detections, so replay timing does not establish end-to-end live throughput.
